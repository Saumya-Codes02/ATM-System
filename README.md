# 🏧 Java ATM System

A console-based ATM application built in Java using Object-Oriented Programming (OOP) principles and Maven.

> **Status:** 🚧 In Development

## 📖 About the Project

This project is part of my Java backend learning journey. The goal is to build an ATM simulation step by step while following clean coding practices and gradually introducing new Java concepts.

## 🎯 Planned Features

* PIN Authentication
* Balance Inquiry
* Cash Deposit
* Cash Withdrawal
* Input Validation
* Transaction History
* File Handling for Data Persistence
* Multiple Account Support

## 🛠️ Tech Stack

* Java
* Maven
* IntelliJ IDEA
* Git & GitHub

## 🚀 Getting Started

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Build the Maven project.
4. Run the `Main` class.
